# Тетрис для BMW iDrive 7

Отдельное офлайн-приложение для MGU Store и автономная браузерная демонстрация. Поле 10 × 20, семь фигур, следующая фигура, контур приземления, счёт, уровни, рекорд, пауза и сохранение партии.

**Экспериментальная версия 0.1.0.** Движок, браузерный интерфейс и адаптер OAP проверены локально. На головном устройстве и в эмуляторе BMW приложение не запускалось: BMW SDK и эмулятор в окружении отсутствуют. Заявленная целевая платформа — ID7; поддержка ID8 не включена.

## Попробовать

Откройте `tetris-preview.html`: файл содержит всю игру и не требует сети или сервера. Нажмите «Продолжить». Клавиши: ←/→ — движение, ↑ или X — поворот по часовой стрелке, Z — обратный поворот, ↓ — шаг вниз, пробел — сброс, P/Esc — пауза. Если фокус на кнопке, пробел нажимает эту кнопку по стандартному поведению браузера. Доступны экранные кнопки.

Во время паузы движение заблокировано. Новая игра требует подтверждения; рекорд сохраняется. При восстановлении партии, уходе с вкладки или скрытии OAP-экрана игра встаёт на паузу. Для продолжения нужен явный запуск. После возврата из подтверждения новой игры тоже остаётся пауза.

На iDrive используются штатные кнопки RHMI: выбрать действие контроллером и нажать. Прямое управление движением фигуры вращением шайбы не подключено. Скорость для такого управления начинается с одного шага за 1,5 секунды. Удобство и скорость обновления картинки необходимо оценить на реальном устройстве; браузер не имитирует задержки RHMI.

## Правила этой версии

- Фигуры выдаются перемешанными наборами по семь, каждый тип встречается один раз в наборе.
- За 1/2/3/4 линии начисляются 100/300/500/800 очков × текущий уровень.
- Каждые 10 линий повышают уровень. Интервал уменьшается на 110 мс за уровень, минимум — 350 мс.
- Ручной шаг вниз даёт 1 очко; сброс даёт 2 очка за пройденную клетку.
- Фигура фиксируется при попытке опуститься на занятый пункт либо сразу после сброса. Отдельного lock delay нет.
- При повороте проверяются небольшие горизонтальные и вертикальные смещения. Это упрощённые повороты, не SRS.
- Занятое место появления фигуры или оставшиеся блоки в двух скрытых верхних строках после фиксации завершают игру.

Нет удержания фигуры, T-spin-бонусов, комбо, матчей и сетевой игры. Это самостоятельная реализация игры с падающими блоками, без официальных графики, звуков и логотипов Tetris.

## Установка через MGU Store

В `dist` находятся `catalog.json` и `dk_tetris@0.1.0.tgz`. Это **исходный пакет**, который Store собирает на головном устройстве с SDK приложения-донора. BMW SDK не включён, готового `javascript/app.js` нет.

Для источника GitHub опубликуйте корень этого проекта в репозитории, добавьте его в Store → Settings → Add source и выберите ветку. Корневой `mgu-repo.json` описывает приложение `dk_tetris`. Альтернативный источник — каталог из `dist` на HTTPS-сервере или USB. Установка выполняется через интерфейс Store.

Тетрис находится в репозитории `mistergahan/mgu-backgammon` рядом с нардами. Установка на автомобиль не проверена. Перед использованием нужно проверить сборку с SDK, плитку, доску, управление контроллером, темп обновления, уход в фон, восстановление сохранения и удаление приложения на ID7.

## Разработка

Зависимости npm не нужны:

```sh
npm test
npm run build
```

Движок и OAP-модули используют синтаксис и API, доступные Node.js 8. Локальные проверки выполнялись на версии из `TETRIS-VALIDATION.txt`; запуск на Node.js 8 пока отдельно не проверен. Для тестов используется современный Node.js.

- `apps/dk_tetris/src/engine.js` — геометрия, столкновения, генератор фигур, гравитация, очистка линий, очки и проверка сохранений.
- `game.js` — пауза и подтверждение новой партии.
- `board.js` — общий рисунок для Canvas и PNG.
- `app.js` — OAP/RHMI, последовательная перерисовка, сохранение и обработка видимости.
- `test/run.js` — тесты движка и случайные последовательности действий.
- `test/oap.js` — SDK-заглушка для проверки адаптера; не эмулятор BMW.

Сохранение — `tetris.json` в папке данных приложения, запись через временный файл и переименование. Промежуточные PNG живут в отдельной папке `/dev/shm`; старые ресурсы освобождаются после вывода новой картинки. Кнопки не пересоздаются на каждом шаге падения, чтобы сохранить фокус контроллера. Сетевых запросов нет.
