# Игры для BMW iDrive 7 / MGU Store

Два отдельных офлайн-приложения в одном источнике Store:

- **Нарды** (`dk_backgammon`): короткие и длинные, вдвоём или с компьютером. Демонстрация: [preview.html](preview.html).
- **Тетрис** (`dk_tetris`): семь фигур, уровни, рекорд, пауза и сохранение. [Инструкция](TETRIS.md), демонстрация: [tetris-preview.html](tetris-preview.html).

Добавьте `mistergahan/mgu-backgammon` в Store → Settings → Add source, выберите ветку `main`. Если источник уже добавлен, выполните **Check now**: тетрис появится отдельным приложением. Общий `dist/catalog.json` содержит оба пакета. `npm test` проверяет обе игры, `npm run build` собирает оба пакета и обе демонстрации.

Оба приложения экспериментальные: целевая платформа — iDrive 7; запуск на BMW и в эмуляторе не проверен.

## Нарды

Приложение для BMW iDrive 7: короткие и длинные нарды, игра вдвоём на одном экране или против компьютера. Интернет для игры не нужен. В комплекте есть самостоятельная браузерная демонстрация с тем же игровым движком.

**Статус: экспериментальная версия 0.1.0.** Логика, исходный пакет и вызовы адаптера проверены локально. Запуск в эмуляторе BMW и на автомобиле не проверен: в окружении нет эмулятора и донорского BMW SDK. Совместимость с iDrive 8 не заявлена. Браузерная демонстрация не является эмулятором OAP.

## Попробовать на компьютере

Откройте `preview.html` в браузере. Этот файл содержит игру целиком, не требует сервера и не загружает внешние ресурсы. Если браузер запрещает локальное сохранение, игра покажет сообщение и продолжит работать без сохранения.

Нажмите «Новая партия…», затем выберите короткие или длинные нарды и режим: с компьютером или вдвоём. Каждый вариант доступен в обоих режимах. Компьютер играет чёрными; его движения запускаются кнопкой «Ход компьютера». Выбор хода — кнопками, без перетаскивания шашек. В браузере доступны Tab и Enter, в OAP используются штатные кнопки RHMI для контроллера iDrive.

Первый бросок определяет начинающего, его же числа используются для первого хода. При равенстве нужно повторить бросок. До передачи очереди можно отменять движения. Позиция, кости, вариант и режим сохраняются после каждого действия; история отмены после перезапуска не восстанавливается. Перед новой партией требуется выбрать режим, поэтому случайное нажатие не сбрасывает игру.

## Правила

В обоих вариантах учитываются максимальное использование костей, обязательная старшая кость при возможности сыграть только одну, четыре движения при дубле и точное/избыточное выбрасывание из дома.

Короткие нарды: стандартная расстановка, противоположные направления движения, сбивание одиночных шашек, обязательный вход с бара, закрытые пункты от двух шашек. Победа оценивается в 1, 2 или 3 очка.

Длинные нарды: все белые начинают на пункте 24, чёрные — на 12. Оба цвета идут в сторону уменьшения номера с переходом 1 → 24. Дом белых — 6–1, чёрных — 18–13. Чужой пункт закрыт даже одной шашкой, сбивания нет. С головы разрешена одна шашка за очередь; на первом ходу второго игрока при 3–3, 4–4 или 6–6 — две. Запрещён сплошной блок из шести пунктов, если ни одна шашка соперника ещё не прошла его по своему маршруту. Победа — 1 очко, марс — 2.

Это одиночные партии без куба удвоения, матчевого счёта, часов и ответного хода после победы. У компьютера простая эвристика: продвижение, выбрасывание и занятые пункты, а в коротких — также сбивания и защита одиночных шашек. Турнирная сила не заявлена.

## Пакет для Store

`dist/catalog.json`, `dist/dk_backgammon@0.1.0.tgz` и `dist/dk_tetris@0.1.0.tgz` образуют общий источник Store. Архив содержит исходный пакет с `mgu-app.json`, а не готовый бинарный OAP. Каталог помечает его `build: "unit"`: Store должен собрать приложение с SDK штатного приложения-донора на головном устройстве. В архиве нет BMW SDK и готового `javascript/app.js`.

Для распространения доступны два пути:

- Добавить `mistergahan/mgu-backgammon` в Store → Settings → Add source и выбрать ветку `main`: корневой `mgu-repo.json` описывает приложение.
- Предоставить папку `dist` как USB-источник или разместить каталог и оба архива на HTTPS-сервере и добавить адрес `catalog.json` в Store. Установку запускают из интерфейса Store.

Установка на автомобиль не проверена. До выпуска нужно проверить установку, плитку, отображение доски, навигацию контроллером, сохранение после перезапуска, возврат в приложение и удаление на реальном iDrive 7 либо в полноценном эмуляторе с SDK.

## Разработка

Не требуются npm-зависимости. Из корня проекта:

```sh
npm test
npm run build
```

Сборка обновляет автономный `preview.html`, исходный архив и каталог с размером и SHA-256. Файлы в `apps/dk_backgammon/src` написаны с учётом Node.js 8, который использует MGU; фактические локальные тесты запускались на версии Node, указанной в `VALIDATION.txt`.

- `engine.js` — позиции, правила обоих вариантов, проверка ходов и компьютер.
- `game.js` — действия, выбор варианта, отмена и снимок сохранения.
- `board.js` — общая отрисовка Canvas/PNG без сторонних графических библиотек.
- `app.js` — адаптер OnlineApp/RHMI, сохранение и управление ресурсами изображения.
- `test/run.js` — правила, некорректные действия, обе разновидности и полные партии.
- `test/oap.js` — проверка последовательности вызовов адаптера через заглушку SDK; не заменяет интеграционный тест.

На устройстве приложение хранит `backgammon.json` в своей папке `data`. Временные PNG создаются в отдельной папке `/dev/shm` и заменяются с освобождением старого ресурса RHMI. Сетевых запросов в приложении нет.
